# Pokémon sprites

48 sprites are bundled locally so Guess Who works without an internet connection.
Images: https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon
Facts and English names: https://pokeapi.co/docs/v2 (Pokémon and Pokémon Species).
Refresh with `python3 scripts/fetch-pokemon.py`.

Pokémon names and artwork belong to Nintendo, Game Freak, and The Pokémon Company.
This is an unofficial personal-use game; no affiliation is implied.
